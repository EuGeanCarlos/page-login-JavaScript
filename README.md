# Página de login

Estudo visual de formulário de login em HTML/CSS. Não há implementação de autenticação ou arquivo JavaScript versionado.

## Tecnologias

- HTML
- CSS

## Funcionalidades e utilização

Abra a página para visualizar o formulário. O botão Entrar não autentica usuários.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/page-login-JavaScript.git
cd page-login-JavaScript
python -m http.server 8000 --directory "."
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
